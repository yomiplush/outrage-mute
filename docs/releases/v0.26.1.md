## Changes

- Extracted post filtering into a shared module independent of the DOM. Language muting, exclusions, focus mode, user dictionary, and scoring retain their existing priority.
- Unified score preview rules across the extension popup, userscript settings, and timeline scoring. The extension popup now correctly applies preset categories and thresholds.
- Reply metadata is read at most once per post evaluation, and only when required.
- Added regression tests for rule priority, boundary conditions, preset scoring, and browser module loading.

The scoring algorithm, dictionary, stored settings, and extension permissions are unchanged.
